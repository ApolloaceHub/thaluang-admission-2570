## 🏛️ ภาพรวมของระบบ (System Overview)
ระบบรับสมัครเรียนออนไลน์ (โควตา) ประจำปีการศึกษา 2570 ได้รับการออกแบบขึ้นเพื่อรองรับการรับสมัครนักเรียน นักศึกษาใหม่ ในระดับประกาศนียบัตรวิชาชีพ (ปวช.) และประกาศนียบัตรวิชาชีพชั้นสูง (ปวส.) ของวิทยาลัยเทคนิคท่าหลวงซิเมนต์ไทยอนุสรณ์ จังหวัดสระบุรี 

โดยหน้าเว็บและระบบได้รับการออกแบบตามมาตรฐานงานราชการและสถานศึกษา มีความเรียบ สุภาพ น่าเชื่อถือ ขอบเหลี่ยมมนไม่เกิน 4px ใช้ฟอนต์ **Sarabun** และคุมโทนด้วยสีกรมท่าเข้ม (`#1F3A5F`)

- **Backend:** Google Apps Script (GAS) Web App & RESTful API
- **Database:** Google Sheets (Applicants, Documents, StatusLog, Staff, Settings)
- **File Storage:** Google Drive (สร้างโฟลเดอร์แยกรายบุคคลอัตโนมัติ)
- **Frontend:** HTML5, Modern Vanilla JavaScript, Responsive CSS รองรับมือถือ แท็บเล็ต และคอมพิวเตอร์

## ✨ คุณสมบัติสำคัญของระบบ

### 1. ส่วนผู้สมัคร (Applicant Section)
- **หน้าแรก:** แสดงประกาศวิทยาลัย กำหนดการรับสมัครและคัดเลือก คุณสมบัติและเอกสารที่ต้องใช้ และรายชื่อสาขาวิชาที่เปิดรับจากฐานข้อมูล
- **แบบฟอร์มใบสมัคร (ตรงตามแบบฟอร์มกระดาษราชการ ข้อ 1–6):**
  - เลือกระดับ: ปวช. / ปวส. (สายตรง) / ปวส. (ม.6/ปวช. ต่างสาขา)
  - **ข้อ 1 ผู้สมัคร:** คำนำหน้า, ชื่อ-สกุล, วันเดือนปีเกิด (พ.ศ.), เลขประจำตัวประชาชน 13 หลัก
  - **ข้อ 2 บิดา:** ชื่อ-สกุล, อายุ, อาชีพ
  - **ข้อ 3 มารดา:** ชื่อ-สกุล, อายุ, อาชีพ
  - **ข้อ 4 ที่อยู่:** บ้านเลขที่, หมู่, ซอย, ถนน, ตำบล, อำเภอ, จังหวัด (Dropdown 77 จังหวัด), รหัสไปรษณีย์, เบอร์โทรศัพท์ 10 หลัก
  - **ข้อ 5 การศึกษาเดิม:** ระดับชั้น, โรงเรียนเดิม, ที่ตั้ง, เกรดเฉลี่ยสะสม (GPAX 5 ภาคเรียน 0.00–4.00), สาขาเดิม
  - **ข้อ 6 สาขาวิชาที่สมัคร:**
    - ปวช. เลือก 2 อันดับ (ระบบป้องกันการเลือกอันดับ 1 และ 2 ซ้ำกัน)
    - ปวส. เลือก 1 สาขาวิชา
    - **ดึงข้อมูลสาขาจากชีต Settings แบบไดนามิก ไม่ฮาร์ดโค้ด**
- **การตรวจสอบความถูกต้อง (Validation):**
  - ตรวจสอบ Checksum เลขบัตรประชาชน 13 หลักตามสูตรคณิตศาสตร์ทางการ
  - ตรวจสอบเบอร์โทรศัพท์ 10 หลักขึ้นต้นด้วย 0
  - ตรวจสอบการสมัครซ้ำด้วยเลขบัตรประชาชนเดิมในปีการศึกษา 2570
  - กล่องข้อความยินยอมตาม พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล (PDPA)
- **อัปโหลดเอกสารแนบ (JPG, PNG, PDF ขนาดไม่เกิน 5 MB):**
  - รูปถ่ายหน้าตรงขนาด 1 นิ้ว (บังคับ)
  - เอกสารแสดงผลการเรียน 5 ภาคเรียน (ปพ.1/รบ.) (บังคับ)
  - สำเนาบัตรประชาชน/ทะเบียนบ้าน (บังคับ)
  - สำเนาเกียรติบัตร/ผลงานความสามารถพิเศษ (ไม่บังคับ)
- **หลังส่งใบสมัคร:**
  - ออกเลขที่ใบสมัครอัตโนมัติ เช่น `Q70-0001`
  - พิมพ์ใบสมัครรูปแบบกระดาษ A4 ตามมาตรฐานแบบฟอร์มกระดาษจริงของวิทยาลัย (มีรูป 1 นิ้วมุมขวาบน ตัวเลขไทยในหัวเอกสาร ตารางรายการหลักฐาน และช่องลงลายมือชื่อผู้สมัครและเจ้าหน้าที่)
- **ตรวจสอบสถานะ (Check Status):**
  - ค้นหาด้วยเลขบัตรประชาชน 13 หลัก
  - แสดงสถานะและหมายเหตุจากเจ้าหน้าที่ ปิดบังเลขบัตรบางส่วนเพื่อความปลอดภัย
  - **กรณีเอกสารไม่ครบ:** ผู้สมัครสามารถอัปโหลดเอกสารแก้ไขเพิ่มเติมผ่านระบบได้ทันที และระบบจะส่งกลับไปให้เจ้าหน้าที่ตรวจซ้ำอัตโนมัติ

### 2. ส่วนเจ้าหน้าที่และงานทะเบียน (Staff Portal)
- **ระบบเข้าสู่ระบบ (Login):** แบ่งสิทธิ์การใช้งาน
  - **ผู้ดูแลระบบ (Admin):** จัดการข้อมูลทุกส่วน เข้าถึงหน้าตั้งค่าระบบ
  - **เจ้าหน้าที่ทะเบียน (Registrar):** ตรวจสอบใบสมัคร ปรับสถานะ มอบตัว ออกรหัสนักเรียน ส่งออกข้อมูล
- **ตารางรายชื่อผู้สมัคร:**
  - ค้นหาและกรองตามระดับชั้น สาขาวิชา และสถานะ
  - ดูเอกสารแนบทั้งหมดผ่าน Google Drive ในหน้าเดียว
- **การปรับปรุงสถานะและการบันทึกประวัติ (Audit Log):**
  - สถานะ: รอตรวจสอบ / เอกสารไม่ครบ / ผ่านการคัดเลือก / ไม่ผ่าน / มอบตัวแล้ว
  - บันทึกลงในชีต `StatusLog` (วันเวลา, เลขที่ใบสมัคร, สถานะเดิม, สถานะใหม่, ผู้ดำเนินการ, หมายเหตุ)
- **ระบบการมอบตัว (Enrollment):**
  - บันทึกการมอบตัวและเลขที่ใบเสร็จ
  - ออกรหัสประจำตัวนักเรียน/นักศึกษาอัตโนมัติ (เช่น `7020xxxx` สำหรับ ปวช., `7030xxxx` สำหรับ ปวส.)
- **แดชบอร์ดสรุปสถิติ (Dashboard Analytics):**
  - สรุปจำนวนผู้สมัครทั้งหมด, รอตรวจ, เอกสารไม่ครบ, ผ่านคัดเลือก, มอบตัวแล้ว
  - กราฟแท่งแบบ Flat เรียบ ใช้โทนสีกรมท่าเข้มไล่น้ำหนัก แยกตามระดับ สาขาวิชา โรงเรียนเดิม และจังหวัด
- **ส่งออกข้อมูล (Export CSV/Excel):** รูปแบบจัดเรียงตามมาตรฐานงานทะเบียน
- **หน้าตั้งค่าระบบ (Settings):**
  - เปิด-ปิดรับสมัครออนไลน์
  - กำหนดช่วงวันรับสมัคร วันประกาศผล วันมอบตัว
  - แก้ไขรายชื่อสาขาวิชา ปวช. และ ปวส. บันทึกลงชีต Settings ทันที
  - กำหนด Token แจ้งเตือนผ่าน LINE Notify และอีเมล

## 📂 โครงสร้างฐานข้อมูล (Google Sheets Schema)

ระบบใช้งาน 5 ชีตหลัก ได้แก่:
1. `Applicants`: จัดเก็บข้อมูลผู้สมัคร ข้อมูลบิดามารดา ที่อยู่ โรงเรียนเดิม เกรด สถานะ และรหัสนักเรียน
2. `Documents`: บันทึกประวัติและลิงก์ไฟล์ Google Drive ของเอกสารแนบทุกรายการ
3. `StatusLog`: บันทึกประวัติการเปลี่ยนแปลงสถานะ (Audit Trail)
4. `Staff`: รายชื่อเจ้าหน้าที่ รหัสผ่านที่เข้ารหัส SHA-256 และสิทธิ์การใช้งาน
5. `Settings`: ค่าการตั้งค่าของระบบ (สถานะเปิด-ปิด, รายชื่อสาขาวิชาแบบ JSON, ข้อความประกาศ)

## 🚀 ขั้นตอนการติดตั้งและ Deploy บน Google Apps Script

### ขั้นตอนที่ 1: สร้าง Google Sheets
1. ไปที่ [Google Sheets](https://sheets.new) แล้วสร้างสเปรดชีตใหม่ ตั้งชื่อว่า `ฐานข้อมูลรับสมัครโควตา_2570_วท.ท่าหลวงฯ`
2. ไปที่เมนู **ส่วนขยาย (Extensions)** -> **Apps Script**

### ขั้นตอนที่ 2: ติดตั้งโค้ด Backend
1. ในหน้า Apps Script ให้ลบโค้ดเดิมใน `Code.gs` ออกทั้งหมด
2. คัดลอกเนื้อหาจากไฟล์ `Code.gs` ในโปรเจกต์นี้ไปวาง
3. ตรวจสอบไฟล์ `appsscript.json` (เปิดได้โดยไปที่ การตั้งค่าโครงการ -> ติ๊กเลือก "แสดงไฟล์ manifest appsscript.json ในตัวแก้ไข")
4. เลือกฟังก์ชัน **`initDatabase`** แล้วกดปุ่ม **เรียกใช้ (Run)** 1 ครั้ง เพื่อให้ระบบสร้างชีตทั้ง 5 ชีต กำหนดหัวตาราง และสร้างโฟลเดอร์ Google Drive โดยอัตโนมัติ

### ขั้นตอนที่ 3: Deploy เป็น Web App
1. กดปุ่ม **การทำให้ใช้งานได้ (Deploy)** -> **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
2. เลือกประเภท: **เว็บแอป (Web app)**
3. กำหนดค่าดังนี้:
   - **คำอธิบาย (Description):** ระบบรับสมัครโควตา 2570 วท.ท่าหลวงฯ
   - **ดำเนินการในฐานะ (Execute as):** ฉัน (Me - บัญชีเจ้าของ)
   - **ผู้มีสิทธิ์เข้าถึง (Who has access):** ทุกคน (Anyone)
4. กด **ทำให้ใช้งานได้ (Deploy)** และคัดลอก **URL เว็บแอป (Web App URL)** ที่ได้ไว้

### ขั้นตอนที่ 4: ผูก URL เข้ากับ Frontend
เปิดไฟล์ `js/app.js` และนำ URL ที่ได้มาใส่ในตัวแปรบรรทัดแรก:
```javascript
let GAS_API_URL = 'https://script.google.com/macros/s/XXXXX/exec';
```

## 🌐 การนำขึ้น GitHub และเปิดใช้งาน GitHub Pages

### 1. คำสั่ง Git สำหรับ Commit และ Push
```bash
git init
git add .
git commit -m "feat: ระบบรับสมัครเรียนออนไลน์ (โควตา) 2570 วท.ท่าหลวงซิเมนต์ไทยอนุสรณ์"
git branch -M main
git remote add origin https://github.com/<YOUR-USERNAME>/<YOUR-REPO-NAME>.git
git push -u origin main
```

### 2. การเปิดใช้งาน GitHub Pages
1. ไปที่แท็บ **Settings** ของ Repository บน GitHub
2. เลือกเมนู **Pages** ที่แถบด้านซ้าย
3. ในส่วน **Build and deployment -> Source** ให้เลือกเป็น `Deploy from a branch`
4. เลือก Branch: `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
5. รอ 1–2 นาที หน้าเว็บจะพร้อมใช้งานผ่าน URL: `https://<YOUR-USERNAME>.github.io/<YOUR-REPO-NAME>/`
